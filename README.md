# Hangman Game 🎮

A terminal-based Hangman game built with Python. Guess the hidden word one letter at a time before using all six incorrect attempts.

## Features

* Random word selection
* ASCII gallows with progressive stages
* Hidden-word display
* Tracks previously guessed letters
* Prevents duplicate guesses from reducing attempts
* Input validation
* Victory and defeat screens

## Technologies Used

* Python 3
* Random module
* Python sets and functions

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python hangman.py
```
